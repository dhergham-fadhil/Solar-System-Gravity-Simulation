# Earth–Sun Gravity Simulation

A small Python/Pygame visualization of a simulated Earth orbiting a fixed Sun under a simplified gravitational model. It displays a star field, the Sun, Earth, and the orbit trail.

## Requirements

- Python 3.10 or later
- Pygame (`pip install -r requirements.txt`)

## Run

```bash
python earth_sun_gravity_simulation.py
```

The simulation uses a 2D display and scaled, illustrative parameters; it is a visualization rather than a precision astronomical model.
